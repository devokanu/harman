# TikTok LIVE Kılavuzu (yerel belge seti)

Statik site. Kök sayfa altı haneli parola sorar; içerik parolanın özetinden türetilen `s/<özet>/` klasöründedir (siteyi ziyaret eden parolasız bulamaz; depo herkese açık olduğu için GitHub'da gezinen görür).

İçerik: `index.html` hub, `adimlar.html` 17 bölüm, `belgeler/` dört belge, `prototip/` 21 sahneli prototip + Radyo Anons + Çiğ Köfte + AI karakter örnekleri.

Parolayı değiştirmek için: `zsh parola_degistir.sh <yeni6hane>` sonra commit ve push.

Görsellerin bir kısmı AI üretimi ve etiketlidir; üçüncü taraf sayfa görüntüleri araştırma kanıtıdır. Başkasına ait video dosyaları depoya konmamıştır.
